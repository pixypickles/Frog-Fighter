# カエルファイター 🐸

Current version: **0.5**

スマホ横持ち向けの、水中ゆっくり格闘ゲームの最初のプロトタイプです。

## 今回入っているもの

- タイトル画面
- 横持ち案内
- キャラクター選択（みどり / あお）
- 水中らしいゆっくり移動・ゆっくり下降
- 円形バーチャルスティック
- パンチ / キック / 舌 / ガード
- 簡単なコンボ表示
- キックで吹っ飛ばした相手を舌で引き寄せる挙動
- シンプルなCPU
- HP / 勝敗 / リスタート
- PCキーボードでの動作確認

## PC操作

- W/A/S/D: 移動
- J: パンチ
- K: キック
- L: 舌
- I: ガード

## GitHub Pagesで公開

1. このフォルダの中身をGitHubリポジトリにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branchを `main`、folderを `/ (root)` にして保存
6. 発行されたURLをスマホで開く

外部ライブラリを使っていないので、そのままGitHub Pagesで動きます。
