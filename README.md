# カエルファイター 🐸

Current version: **0.8**

スマホ横持ち向けの、水中ゆっくり格闘ゲームの最初のプロトタイプです。

## 今回入っているもの

- タイトル画面
- 横持ち案内
- キャラクター選択（みどり / あお）
- 水中らしいゆっくり移動・ゆっくり下降
- 円形バーチャルスティック
- パンチ / キック / 舌 / ガード
- 簡単なコンボ表示
- キックで吹っ飛ばした相手を舌で引き寄せる挙動
- シンプルなCPU
- HP / 勝敗 / リスタート
- PCキーボードでの動作確認

## PC操作

- W/A/S/D: 移動
- J: パンチ
- K: キック
- L: 舌
- I: ガード

## GitHub Pagesで公開

1. このフォルダの中身をGitHubリポジトリにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branchを `main`、folderを `/ (root)` にして保存
6. 発行されたURLをスマホで開く

外部ライブラリを使っていないので、そのままGitHub Pagesで動きます。

## 次に足したいもの

- 効果音・BGM

- ストーリー


## v0.4

- ニュートラル時の脚を閉じ気味に変更
- パンチ中は元の前腕を非表示にして攻撃腕へ差し替え
- キック中は元の前脚を非表示にして攻撃脚へ差し替え


## v0.5

- 舌はコンボ外でも小ダメージ＋引き寄せ
- 引き寄せ中にもう一度舌で「舌投げ」
- 通常は相手を回転させながら前方の壁へ投げる
- スティックを下に入れながら2回目の舌で床へ叩きつける
- 壁・床への激突で追加ダメージ
- 舌投げ中は相手キャラが回転


## v0.6

- 最初の「スマホを横持ちしてください」画面にバージョン番号を表示

## v0.7

- 縦持ち時に実際に表示される「スマホを横持ちしてください」画面へ VERSION 0.7 を追加
- パンチ / キック / 舌 / ガードの操作ボタンをさらに半透明化
- 舌の2段目投げを床投げから後方投げへ変更
- 舌投げは相手を回転させながら自分の背後方向へ飛ばす

## v0.8

- 全体移動速度を少し低下
- 水中らしく慣性を少し強め、沈下速度もさらにゆっくりに
- パンチの発生と硬直を少し遅く変更
- キックの発生と硬直をさらに重めに変更
- 舌で引き寄せられている側が舌ボタンを押すと「投げ抜け」
- 投げ抜け成功時はお互いの舌が伸びた状態になり、投げには移行せず中央へ接近
- CPUも一定確率で舌投げを抜ける
