# カエルファイター 🐸

Current version: **1.7**

スマホ横持ち向けの、水中ゆっくり格闘ゲームの最初のプロトタイプです。

## 今回入っているもの

- タイトル画面
- 横持ち案内
- キャラクター選択（みどり / あお）
- 水中らしいゆっくり移動・ゆっくり下降
- 円形バーチャルスティック
- パンチ / キック / 舌 / ガード
- 簡単なコンボ表示
- キックで吹っ飛ばした相手を舌で引き寄せる挙動
- シンプルなCPU
- HP / 勝敗 / リスタート
- PCキーボードでの動作確認

## PC操作

- W/A/S/D: 移動
- J: パンチ
- K: キック
- L: 舌
- I: ガード

## GitHub Pagesで公開

1. このフォルダの中身をGitHubリポジトリにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branchを `main`、folderを `/ (root)` にして保存
6. 発行されたURLをスマホで開く

外部ライブラリを使っていないので、そのままGitHub Pagesで動きます。

- 壁・床への激突で追加ダメージ
- 舌投げ中は相手キャラが回転

## v0.8

- キックの発生と硬直をさらに重めに変更
- 舌で引き寄せられている側が舌ボタンを押すと「投げ抜け」
- 投げ抜け成功時はお互いの舌が伸びた状態になり、投げには移行せず中央へ接近
- CPUも一定確率で舌投げを抜ける

## v0.9

- 全体移動をさらに少しスロー化
- 水中の慣性とゆっくりした沈下を強化
- パンチの発生と硬直をさらに少し遅く
- キックをより重いテンポに変更
- 通常ヒット時に大きめのリングエフェクトを追加
- ヒット時の飛沫風パーティクルを強化
- 被弾時に片目または両目を閉じる表情を追加

## v1.0

- ガード時の半円シールド表示を廃止
- ガード中は通常の腕を消し、専用の腕ポーズへ差し替え
- 胸の前で両腕を交差するガード姿勢を追加
- 敵に近い側の腕は少し上から斜めに構える
- 敵から遠い側の腕は胸へ真っ直ぐ内側に伸ばす
- 短い腕でもクロスが分かるよう、手先を丸く強調

## v1.1

- 舌投げで回転している間は常にやられ顔
- ガード開始から約0.28秒を緩めのジャストガード受付に設定
- ジャストガード成功時は攻撃側に約0.42秒の隙
- ジャストガード成功時に表示とエフェクトを追加
- ガードボタンを650ms以内に3回押すと「水押し波」
- 水押し波はダメージ0で、相手を水圧で吹き飛ばす
- 波発動時は両手を前へ押し出す専用ポーズ

## v1.2

- 舌投げ回転中、壁に当たる直前のガード入力で「受け身」
- 受け身受付は約0.24秒
- 受け身成功時は壁ダメージ0、回転停止、軽く跳ね返る
- 受け身成功時に `UKEMI!` 表示
- 床への叩きつけは受け身対象外
- ガード3連打の水押し波を大幅に強化
- 水押し波の移動速度も少し上昇

## v1.3

- バーチャルスティックで同じ方向へ2回入力すると短い水中ダッシュ
- 1回目の入力後に一度ニュートラルへ戻し、約0.32秒以内に同方向へ再入力すると発動
- 8方向対応（上下左右＋斜め）
- ダッシュは約0.20秒の短い加速
- 誤発動防止のクールダウンあり
- PCのWASDも同じキー2回でダッシュ可能

## v1.4

- スマホのダッシュ処理を実際に組み直し
- 1回目の方向入力で指を離した方向を記録
- 0.45秒以内に同方向へ再入力すると発動
- 方向判定を少し緩めて8方向対応
- ダッシュ成功時に `DASH!` 表示
- ダッシュ時に水泡エフェクトを追加
- ダッシュの加速を見て分かる程度に強化
- PCではW/A/S/Dの同キー2回でも確認可能

## v1.5

- 練習モードでは敵AIとゲームオーバーを無効化
- 将来の「ミニゲーム」用メニュー枠を追加
- キャラクター選択カード下に専用必殺技の表示欄を追加する準備
- 必殺技コマンド自体は次の段階で実装予定
