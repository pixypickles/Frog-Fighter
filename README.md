# カエルファイター 🐸

Current version: **1.2**

スマホ横持ち向けの、水中ゆっくり格闘ゲームの最初のプロトタイプです。

## 今回入っているもの

- タイトル画面
- 横持ち案内
- キャラクター選択（みどり / あお）
- 水中らしいゆっくり移動・ゆっくり下降
- 円形バーチャルスティック
- パンチ / キック / 舌 / ガード
- 簡単なコンボ表示
- キックで吹っ飛ばした相手を舌で引き寄せる挙動
- シンプルなCPU
- HP / 勝敗 / リスタート
- PCキーボードでの動作確認

## PC操作

- W/A/S/D: 移動
- J: パンチ
- K: キック
- L: 舌
- I: ガード

## GitHub Pagesで公開

1. このフォルダの中身をGitHubリポジトリにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branchを `main`、folderを `/ (root)` にして保存
6. 発行されたURLをスマホで開く

外部ライブラリを使っていないので、そのままGitHub Pagesで動きます。

## 次に足したいもの

- パンチ×3 → キック → 舌 → キックを、専用のコンボとしてより気持ちよく調整
- 攻撃モーションとヒットストップ
- カエル画像・アニメーション
- 魚 / ザリガニ
- キャラごとの重量・浮力・舌の長さ
- 効果音・BGM
- ステージ
- ストーリー


## v0.4

- ニュートラル時の脚を閉じ気味に変更
- パンチ中は元の前腕を非表示にして攻撃腕へ差し替え
- キック中は元の前脚を非表示にして攻撃脚へ差し替え


## v0.5

- 舌はコンボ外でも小ダメージ＋引き寄せ
- 引き寄せ中にもう一度舌で「舌投げ」
- 通常は相手を回転させながら前方の壁へ投げる
- スティックを下に入れながら2回目の舌で床へ叩きつける
- 壁・床への激突で追加ダメージ
- 舌投げ中は相手キャラが回転


## v0.6

- 最初の「スマホを横持ちしてください」画面にバージョン番号を表示

## v0.7

- 縦持ち時に実際に表示される「スマホを横持ちしてください」画面へ VERSION 0.7 を追加
- パンチ / キック / 舌 / ガードの操作ボタンをさらに半透明化
- 舌の2段目投げを床投げから後方投げへ変更
- 舌投げは相手を回転させながら自分の背後方向へ飛ばす

## v0.8

- 全体移動速度を少し低下
- 水中らしく慣性を少し強め、沈下速度もさらにゆっくりに
- パンチの発生と硬直を少し遅く変更
- キックの発生と硬直をさらに重めに変更
- 舌で引き寄せられている側が舌ボタンを押すと「投げ抜け」
- 投げ抜け成功時はお互いの舌が伸びた状態になり、投げには移行せず中央へ接近
- CPUも一定確率で舌投げを抜ける

## v0.9

- 全体移動をさらに少しスロー化
- 水中の慣性とゆっくりした沈下を強化
- パンチの発生と硬直をさらに少し遅く
- キックをより重いテンポに変更
- 通常ヒット時に大きめのリングエフェクトを追加
- ヒット時の飛沫風パーティクルを強化
- 被弾時に片目または両目を閉じる表情を追加
- 被弾時は一瞬、口角が下がる痛そうな表情に変更

## v1.0

- ガード時の半円シールド表示を廃止
- ガード中は通常の腕を消し、専用の腕ポーズへ差し替え
- 胸の前で両腕を交差するガード姿勢を追加
- 敵に近い側の腕は少し上から斜めに構える
- 敵から遠い側の腕は胸へ真っ直ぐ内側に伸ばす
- 短い腕でもクロスが分かるよう、手先を丸く強調

## v1.1

- 舌投げで回転している間は常にやられ顔
- ガード開始から約0.28秒を緩めのジャストガード受付に設定
- ジャストガード成功時は攻撃側に約0.42秒の隙
- ジャストガード成功時に表示とエフェクトを追加
- ガードボタンを650ms以内に3回押すと「水押し波」
- 水押し波はダメージ0で、相手を水圧で吹き飛ばす
- 波発動時は両手を前へ押し出す専用ポーズ

## v1.2

- 舌投げ回転中、壁に当たる直前のガード入力で「受け身」
- 受け身受付は約0.24秒
- 受け身成功時は壁ダメージ0、回転停止、軽く跳ね返る
- 受け身成功時に `UKEMI!` 表示
- 床への叩きつけは受け身対象外
- ガード3連打の水押し波を大幅に強化
- 水押し波の移動速度も少し上昇
